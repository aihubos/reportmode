# Report Hub 추천·인기 카드 성능 확인

로컬 정적 빌드의 `/archive/`를 실제 Chromium으로 측정했다.

| 모드 | 성능 | 접근성 | 권장사항 | SEO | FCP | LCP | TBT | CLS |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 모바일 | 57 | 96 | 100 | 100 | 8.2s | 10.5s | 0ms | 0.001 |
| 데스크톱 | 88 | 96 | 100 | 100 | 1.4s | 1.7s | 0ms | 0 |

새 기능은 기존 아카이브 HTML 안의 작은 정적 목록과 관리자 API 요청 1개를 추가한다. 메인 스레드 차단과 레이아웃 이동은 사실상 없었다. 모바일 초기 표시 시간은 기존 55개 보고서의 큰 단일 HTML 문서와 이미지 로딩 영향이 크며, 향후 아카이브 목록 분할 또는 지연 렌더링 작업으로 별도 개선한다.
