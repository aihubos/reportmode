# Report Hub 추천·인기 카드 시각 QA

## 범위

- 공개 아카이브 최상단 추천글 3개와 인기글 3개
- 관리자 모드의 별표 선택·해제와 최대 3개 제한
- 기존 삭제 버튼과 새 별표 버튼의 겹침 방지

## 화면 크기

- 1280 × 900: `archive-1280.png`
- 768 × 900: `archive-768.png`
- 390 × 844: `archive-390.png`
- 390 × 844 관리자 상태: `admin-star-390.png`

## 확인 결과

- 1280px와 768px에서는 추천·인기 목록이 두 열로 각각 3개씩 표시된다.
- 390px에서는 추천 목록 다음에 인기 목록이 한 열로 쌓인다.
- 세 화면 모두 `scrollWidth === innerWidth`로 가로 넘침이 없다.
- 제목은 두 줄에서 정리되고 실제 보고서 표지가 고정 크기로 표시된다.
- 관리자 잠금 해제 후 각 게시물에 별표가 나타난다.
- 별표 선택 즉시 해당 게시물이 상단 추천 목록 첫 항목으로 이동한다.
- 별표와 삭제 버튼은 게시물 하단의 별도 조작 줄에 표시되어 본문·표지와 겹치지 않는다.
- 추천하지 않은 빈 자리는 최신 공개 글로 채워지며, 숨긴 글은 두 목록에서 제외된다.
- 브라우저 콘솔 오류와 경고는 0건이었다.

## 인터랙션 상태

- 기본: 빈 추천 자리는 최신 글로 채운다.
- 선택: 채운 파란 별과 `추천 해제` 접근성 이름을 표시한다.
- 제한: 네 번째 글을 선택하면 `추천 글은 최대 3개까지 선택할 수 있습니다.`를 표시한다.
- API 실패: 정적 추천 목록은 유지하고 관리자 상태 영역에 안내한다.
- 키보드: 추천 카드와 별표 버튼 모두 기본 Tab·Enter 조작과 `focus-visible` 윤곽선을 제공한다.
- 모션 감소: 카드 이동 전환을 제거한다.

## 디자인 시스템 확인

- 새 카드에는 기존 Report Hub의 종이 표면, 경계선, Toss Blue, 포커스 토큰만 사용했다.
- 그라데이션, 글로우, 중첩 그림자를 추가하지 않았다.
- 전체 `magazine.css` 검사기는 과거 코드까지 포함해 미등록 색상 96개와 간격 165개를 보고한다. 이번 기능 범위의 새 카드 색상은 CSS 변수로 제한했으며, 기존 전역 스타일 부채는 별도 정리 대상이다.
