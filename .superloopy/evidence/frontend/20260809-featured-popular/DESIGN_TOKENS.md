# Report Hub 추천·인기 카드 시각 목표

기존 `DESIGN.md`를 그대로 사용하며 새 색상·글꼴·그림자를 만들지 않는다.

## 배치 목표

```text
┌──────────────────────────────────────────────────────────────┐
│ 지금 읽을 보고서                                             │
│ ┌────────────────────────────┐ ┌────────────────────────────┐ │
│ │ ★ Jeremy's Pick           │ │ 인기글                     │ │
│ │ 1  제목 · 날짜 · 표지      │ │ 1  제목 · 조회수 · 표지    │ │
│ │ 2  제목 · 날짜 · 표지      │ │ 2  제목 · 조회수 · 표지    │ │
│ │ 3  제목 · 날짜 · 표지      │ │ 3  제목 · 조회수 · 표지    │ │
│ └────────────────────────────┘ └────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- 1280px: 두 목록을 1:1 열로 배치한다.
- 768px: 두 목록을 1:1로 유지하되 표지는 작게 줄인다.
- 390px: 추천 목록 다음에 인기 목록을 세로로 쌓는다.
- 카드 전체는 `--rh-paper`, `--rh-border`, 18px 반경을 사용한다.
- 목록 항목은 순번, 제목, 보조 정보, 실제 보고서 표지로 구성한다.
- 관리자 별표는 기존 관리자 모드에서만 보이며, 선택은 Toss Blue와 채운 별로 구분한다.
- 별표는 최대 3개이며 선택 직후 상단 추천 목록에 반영한다.
- 인기글은 `reports/view-counts.json`의 숫자가 큰 순서로 3개를 표시한다.

## 상태

- 추천 미선택: 최신 공개 글로 빈 자리를 채운다.
- 로딩: 정적 기본 추천 3개를 유지한다.
- API 오류: 정적 기본 추천을 유지하고 관리자 상태 영역에 오류를 표시한다.
- 숨긴 보고서: 추천·인기 목록에서도 제외한다.
