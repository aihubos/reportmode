# Report Hub UI target

- Direction: Apple식 절제, Toss Blue 선택 신호, 보고서가 시각적으로 가장 큰 층이다.
- Main: 소개 카드 없이 도서관 목록을 우선한다. 상단에는 Report Hub, 방문 수, 초록색 네이버 블로그 카드 하나만 둔다.
- Portrait: 1180px 이상에서 A4 용지 오른쪽 여백에 160px 세로 메뉴를 둔다.
- Mobile: 390px 안에서 메뉴와 도서관 제어가 가로 스크롤 없이 보인다.
- Comments: 흰색 카드, Toss Blue 등록 버튼, 인라인 수정·삭제, 서버 확인 관리자 배지다.
- Tokens: 자세한 색상·타입·간격·컴포넌트 규칙은 저장소 `DESIGN.md`를 단일 기준으로 사용한다.
