CHAPTER 2 · AI 101

AI는 사람처럼 느끼는 존재가 아니라, 입력에서 패턴을 찾아 출력을 만드는 시스템입니다

인공지능은 하나의 제품명이 아니라 큰 기술 범주입니다. 지금 우리가 자주 쓰는 생성형 AI는 그 안에서 글·이미지·음성·코드 같은 새 결과를 만드는 분야입니다.

🧠

가장 쉬운 정의

AI는 사람이 하던 판단·예측·생성 작업 일부를 데이터와 계산으로 수행하는 시스템입니다. “사람과 똑같이 생각한다”보다 “특정 입력에서 유용한 출력을 만든다”가 안전한 표현입니다.

01

입력

AI가 받는 재료

텍스트, 이미지, 음성, 센서 값, 표, 코드 등입니다. 입력이 모호하거나 틀리면 결과도 흔들립니다.

02

패턴 처리

학습한 관계 사용

모델은 학습 과정에서 얻은 수많은 숫자 가중치를 사용해 입력의 관계를 계산합니다.

03

출력

예측 또는 생성

분류, 추천, 점수, 답변, 이미지, 계획처럼 목적에 맞는 결과를 냅니다.

과한 표현

“AI가 이해하고 믿는다”

사람의 의식·의도와 같은 의미로 받아들이기 쉽습니다.

“무엇을 찾는가, 규칙이 고정됐는가, 새 결과를 생성하는가, 실제 행동까지 하는가” 네 질문으로 구분하면 쉽습니다.

Q1

결과가 이미 존재하나요?

그렇다면 검색이 중심일 가능성이 큽니다. AI는 검색 결과를 요약할 수 있지만 원문과 동일하지 않습니다.

Q2

절차가 완전히 고정됐나요?

그렇다면 일반 자동화가 더 싸고 예측 가능할 수 있습니다. 모든 일을 에이전트로 만들 필요는 없습니다.

Q3

환경을 보고 다음 행동을 바꾸나요?

도구 결과를 읽고 계획을 수정한다면 에이전트 성격이 강합니다.

“학습 데이터가 있었다”와 “그 문서를 정확히 보관하고 있다”는 다른 말입니다. 최신 사실과 근거는 별도 검색·RAG·도구로 보완해야 합니다.

1

데이터 준비

2

예측 문제

3

오차 계산

정답과 예측 차이를 수치로 측정합니다.

4

가중치 조정

오차가 줄어드는 방향으로 모델 숫자를 조금씩 바꿉니다.

5

CHAPTER 2 · TRAINING VS INFERENCE

학습은 모델을 만드는 긴 공정이고, 추론은 완성된 모델을 매번 사용하는 순간입니다

학교를 세우고 교과서를 만드는 일과, 학생이 오늘 질문에 답하는 일을 구분하면 비용·속도·업데이트를 이해하기 쉬워집니다.

PHASE 1

사전학습 · 기본기를 만듦

대규모 데이터에서 언어·이미지·코드의 일반 패턴을 학습합니다. 막대한 계산이 필요하며 사용자가 매 질문마다 하는 일이 아닙니다.

PHASE 2

후처리 학습 · 행동을 다듬음

지시 따르기, 안전성, 선호도, 도구 사용 같은 행동을 조정합니다. 미세조정·강화학습 등이 여기에 포함될 수 있습니다.

PHASE 3

추론 · 지금 답을 만듦

사용자의 입력을 토큰으로 바꾸고, 모델 가중치를 사용해 출력 토큰을 생성합니다. API 사용량과 응답 지연은 주로 이 단계에서 체감합니다.

⚡
핵심: 모델이 “어제 뉴스를 모른다”는 문제를 해결하려고 매일 전체 학습을 다시 하는 대신, 검색·RAG·도구로 최신 자료를 그때그때 넣는 방식이 흔합니다.

CHAPTER 2 · WHAT IS A MODEL?

모델은 앱이 아니라, 입력을 출력으로 바꾸는 숫자 규칙 묶음입니다

ChatGPT·Claude·Gemini 같은 서비스 화면과 그 안에서 선택되는 모델, 그리고 모델을 호출하는 API를 분리해 이해해야 가격·기능·보안 비교가 정확해집니다.

APP
사용자 앱·서비스대화 화면, 파일 업로드, 기록, 프로젝트, 결제, 정책
예: ChatGPT
MODEL
AI 모델입력을 토큰·벡터로 처리해 출력을 만드는 가중치와 구조
예: GPT‑5.6 Terra
API
프로그램 연결 규격내 앱이 모델·도구를 호출하고 사용량을 받는 통로
예: Responses API
AGENT
실행 하네스프롬프트·도구·루프·상태·권한을 묶어 업무를 끝내는 구조
예: Hermes
W

가중치

학습으로 조정된 수많은 숫자입니다. 입력의 관계를 계산하는 모델의 장기적 패턴 저장소입니다.

T

토크나이저

사람의 텍스트를 모델이 처리하는 조각과 숫자 ID로 바꾸고, 출력을 다시 텍스트로 되돌립니다.

C

컨텍스트 창

한 번의 추론에서 입력·대화·도구 결과·출력이 함께 사용하는 임시 작업 공간입니다.

✓
구매 판단 팁: “어떤 앱을 쓰는가?”와 “어떤 모델을 쓰는가?”를 따로 질문하세요. 같은 앱에서도 모델·요금제·도구 권한에 따라 경험이 달라질 수 있습니다.

AI Agent = 모델 + 목표 + 도구 + 반복 루프 + 상태·기억 + 안전장치. OpenAI는 에이전트를 사용자를 대신해 독립적으로 과업을 완수하는 시스템으로 설명합니다.[19]

Tools · 도구

CHAPTER 7 · INGEST · LINT · CRON

매일 새 자료를 Ingest하고, 주기적으로 Lint하면 Second Brain이 쌓이기만 하는 창고가 되는 것을 막을 수 있습니다

Cron은 정해진 시간에 반복 작업을 실행하는 예약입니다. 자동화 전에 시간·범위·수정 권한·보고 채널을 확인하고 승인받습니다.

I

000_Inbox의 새 자료를 읽고 원본은 보존하며 관련 Wiki를 갱신합니다. 이미 처리한 자료는 중복 반영하지 않습니다.

L

Lint · 점검

깨진 링크·중복·형식 위반·출처 누락을 찾습니다. 의미가 바뀌는 수정은 자동으로 하지 않습니다.

C

Cron · 예약

한 번 또는 반복 실행하고 결과를 원래 채팅·파일·설정한 플랫폼에 전달할 수 있습니다.[24]
