## Upload steps

1. ZIP의 `reports/260810-49-ai-optimism-human-verification-v1-0-0/` 폴더를 저장소의 `reports/` 아래에 그대로 추가합니다.
2. 저장소의 기존 `archive/index.html`과 sitemap 원문을 먼저 읽은 뒤, ZIP 루트의 `archive-entry.json`과 `sitemap-entry.xml`을 안전하게 병합합니다.
3. 기존 archive 또는 sitemap을 빈 파일로 덮어쓰지 않습니다.
4. `upload-manifest.json`의 SHA256과 파일 크기로 무결성을 확인합니다.
5. 외부 공개 전, 본문의 예시 수치가 실제 시장 사실로 오해되지 않는지와 출처 링크 상태를 사람이 최종 검토합니다.

GitHub push와 외부 블로그 발행은 이 산출물 생성 과정에서 수행하지 않았습니다.
