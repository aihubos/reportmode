## Upload
1. ZIP을 풉니다.
2. `reports/260810-01-ethan-mollick-ai-work-education-v1-0-0/` 폴더를 저장소의 `reports/` 아래에 그대로 추가합니다.
3. `archive-entry.json`과 `sitemap-entry.xml`은 기존 archive/sitemap을 읽은 뒤 안전하게 병합합니다. 기존 파일을 빈 내용으로 덮어쓰지 않습니다.
4. `upload-manifest.json`의 SHA256과 파일 크기를 확인합니다. 매니페스트 자기 자신은 재귀 해시 문제로 목록에서 제외했습니다.
5. 로컬 또는 GitHub Pages preview에서 모바일 320px, 데스크톱, 인쇄 화면을 확인합니다.
