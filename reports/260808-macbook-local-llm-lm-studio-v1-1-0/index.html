START WITH THE RIGHT PRODUCT

Local LLM은 “내 Mac에서 실행되는 AI 두뇌”이고, LM Studio는 그 두뇌를 여는 앱입니다

모델 파일은 전자책, LM Studio는 전자책 리더, 통합 메모리(RAM)는 책을 펼쳐 놓는 책상이라고 생각하면 쉽습니다. 2026년에는 같은 사이트에 Bionic도 함께 보이므로 두 제품을 먼저 구분해야 합니다.

한 문장 결론

입문자는 LM Studio의 User 모드로 시작해 모델 검색·다운로드·채팅을 익힌 뒤, API나 세부 설정이 필요할 때만 Developer 모드를 켜는 것이 안전합니다.5

BEFORE YOU INSTALL

설치 전에는 칩·macOS·RAM·저장공간 네 가지만 확인하세요

LM Studio 공식 요구사항은 macOS 14 이상과 Apple Silicon을 요구하고 16GB 이상 RAM을 권장합니다. 8GB도 가능하지만 작은 모델과 짧은 context가 필요합니다.2

내 Mac 확인 순서

1

 메뉴 → 이 Mac에 관하여를 열어 칩과 메모리를 확인합니다.16

2

항목명이 Chip이면 Apple Silicon, Processor이면 Intel입니다. Intel Mac은 현재 공식 지원 대상이 아닙니다.2

3

macOS 버전이 14 이상인지 확인합니다.

4

첫 모델과 캐시를 위해 최소 20~30GB의 여유 공간을 준비합니다. 이는 이 가이드의 보수적 운영 권장값입니다.

모델 이름보다 먼저 “내 RAM에 안전하게 들어가는가?”를 판단하세요

필요 메모리는 모델 파일뿐 아니라 context, 이미지 입력, 런타임, 동시 요청에 따라 달라집니다. 아래는 공식 최소 요구사항과 현재 모델 파일 규모를 바탕으로 한 이 가이드의 보수적 시작점이며 절대적인 성능 보장은 아닙니다.

첫 선택

GGUF Q4 또는 MLX 4-bit

LM Studio 문서는 양자화 모델에서 가능하면 4-bit 이상을 선택하라고 안내합니다. 입문자는 용량과 품질의 균형이 좋은 4-bit부터 시작하세요.4

Apple Silicon

MLX

Apple Silicon에 맞춘 실행 형식입니다. LM Studio가 MLX 엔진을 지원하지만 모든 모델에서 항상 GGUF보다 빠르다고 단정할 수는 없습니다.

호환성

GGUF

llama.cpp 계열에서 널리 쓰이는 형식입니다. 같은 모델에서 MLX 로드가 불안정하면 GGUF Q4를 대안으로 시험할 수 있습니다.

고급 확인: Developer 모드 또는 터미널을 사용할 수 있다면 lms load --estimate-only <model_key>로 context를 포함한 메모리 예상치를 로드 전에 확인할 수 있습니다.12

DOCUMENTS & PRIVACY

문서 대화는 편리하지만 “로컬 모델인지, 어떤 연결을 켰는지”까지 확인해야 안전합니다

LM Studio는 PDF·DOCX·TXT를 채팅에 첨부할 수 있습니다. 짧은 문서는 전체를 context에 넣고, 긴 문서는 관련 부분을 찾는 RAG를 사용합니다.7

문서 대화 4단계

1
모델을 먼저 Load문서만 붙여서는 답할 모델이 없습니다.
2
클립 또는 드래그앤드롭PDF·DOCX·TXT를 채팅에 첨부합니다.
3
질문에 고유 키워드 포함문서명, 장, 제품명, 날짜를 적으면 검색 정확도가 올라갑니다.
4

OPTIONAL ADVANCED STEP

LM Studio는 채팅 앱을 넘어 localhost의 로컬 AI 서버가 될 수 있습니다

Developer 탭에서 서버를 켜면 기존 OpenAI 클라이언트의 base URL을 http://localhost:1234/v1로 바꿔 로컬 모델을 사용할 수 있습니다.13

초보자가 알아야 할 세 가지

처음에는 채팅만 사용해도 충분합니다. 아래 기능은 자동화·코딩 도구 연동이 필요할 때만 켭니다.

1localhost는 내 Mac 자기 자신을 뜻합니다.
2기본 포트 예시는 1234이며 앱 설정에서 바꿀 수 있습니다.
3같은 Wi‑Fi의 다른 기기에 열려면 Serve on Local Network를 켜야 하며, 이때 인증을 함께 사용해야 합니다.14

서버가 켜졌는지 확인하는 가장 짧은 명령

curl http://localhost:1234/v1/models

OpenAI 호환 채팅 요청 예시

curl http://localhost:1234/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "LM Studio에 표시된 모델 식별자",
    "messages": [
      {"role": "user", "content": "한국어로 한 줄 인사해줘"}
    ]
  }'
보안: Serve on Local Network를 켠 상태에서 인증 없이 사용하지 마세요. MCP가 파일 시스템이나 사내 데이터에 접근한다면 LM Studio의 인증·권한 설정을 함께 검토해야 합니다.
