루머

현재까지 겹치는 형태 보도

명칭은 ‘iPhone Ultra’ 또는 ‘iPhone Fold’로 불리지만 공식 제품명은 아닙니다. 책처럼 가로로 펼치는 북 스타일, 외부 화면과 내부 대화면 조합이 다수 보도에서 겹칩니다. 수치가 충돌하는 항목은 하나로 합치지 않았습니다.

  • 외부 5.3~5.5인치 · 내부 7.6~7.8인치
  • 펼쳤을 때 5mm 미만, 접으면 약 9~9.5mm 두께 보도
  • 티타늄 프레임과 액체금속·스테인리스 기반 힌지 보도

루머

칩·카메라·인증 예상

2nm 공정 A20 Pro, 12GB RAM, 애플 C2 5G 모뎀, 베이퍼 챔버 냉각이 거론됩니다. 후면 48MP 메인과 초광각 중심 구성, 망원 렌즈 제외 가능성, Face ID 대신 측면 Touch ID 가능성이 함께 보도됩니다.

  • 저장공간 256GB · 512GB · 1TB 예상
  • 얇은 구조로 생체인증 방식 변경 가능성
  • 카메라 구성은 아직 확정되지 않음

사실

배터리 수치는 상충한다

규제 자료 기반 보도는 듀얼 셀 합계 4,883mAh를 제시하지만, 별도 루머는 5,400~5,800mAh 범위를 거론합니다. 용량보다 외부·내부 화면별 실사용 시간이 더 중요합니다.

  • 4,883mAh 듀얼 셀 보도
  • 더 높은 용량 루머와 충돌
  • 공식 사양 아님

출처: 9to5Mac — 4,883mAh 듀얼 셀 배터리 보도

전망

초기 물량과 일정 리스크

2026년 가을 공개설과 함께, 초기 출하가 1~2개월 늦어질 가능성과 초기 물량 부족 가능성이 제기됩니다. 가격은 약 1,999~2,500달러 시작가 범위로 거론됩니다.

  • 초기 생산량 제약 가능성
  • 프리미엄 가격대 예상
  • 1세대 장기 내구성은 미검증

분석

하드웨어보다 멀티태스킹 완성도

문서 검토·독서·영상·원격 업무는 좋아질 수 있지만, iOS의 앱 전환과 멀티태스킹 완성도가 하드웨어보다 중요한 평가 항목입니다. 앱이 넓은 화면을 제대로 활용하지 못하면 하드웨어 장점이 축소됩니다.

  • 외부 화면 빠른 작업 + 내부 화면 병행 작업
  • 앱 최적화 수준이 체감 가치를 좌우
  • 1세대 프리미엄을 감수할지 별도 판단 필요

02

화면 켠 실제 사용 시간

배터리 용량보다 외부·내부 화면별 실사용 시간을 봅니다.

03

주름과 반사

정면 사진이 아닌 측면 조명과 손가락 촉감 평가가 중요합니다.

04

AppleCare+와 수리비

내부 화면·힌지 교체 비용과 보증 범위를 먼저 확인합니다.

05

멀티태스킹 완성도

앱 전환, 화면 비율 대응, 키보드 입력까지 실제 작업으로 검수합니다.
