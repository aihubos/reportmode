HOW MOA REALLY WORKS

여러 AI가 회의하지만,
실제 업무를 실행하는 담당자는 한 명입니다

Hermes MOA에서 레퍼런스 모델은 ‘자문위원’, 어그리게이터는 ‘최종 책임자’에 가깝습니다. 최종 책임자가 자문을 읽고 답변을 쓰며, 필요한 경우 Hermes의 도구를 호출합니다.

정확한 한 문장

MOA는 ‘모델 합성’이 아니라 ‘의견 수렴형 실행’입니다. 레퍼런스 모델의 분석을 비공개 컨텍스트로 붙인 뒤 어그리게이터를 정상 Hermes 모델처럼 호출합니다 [2].

04
약 6분

MOA 프리셋 생성

레퍼런스 2개와 Solar Pro 4 어그리게이터를 지정합니다. 처음부터 4~5개 모델을 넣지 말고 품질·지연·비용을 비교하며 늘립니다.

Settings → Model → Mixture of Agents → Add preset → References 2개 → Aggregator: Upstage / solar-pro4
  • ✓
    권장 시작값: reference_max_tokens: 600
  • ✓
    권장 cadence: fanout: user_turn
config.yaml · 예시 구성
moa:
  default_preset: kr-report
  privacy_filter: full  # 민감정보가 자문·어그리게이터로 재노출되는 범위 축소
  presets:
    kr-report:
      reference_models:
        - provider: openai-codex
          model: gpt-5.5
          reasoning_effort: low
        - provider: openrouter
          model: deepseek/deepseek-v4-pro
      aggregator:
        provider: upstage
        model: solar-pro4
        reasoning_effort: medium
      reference_max_tokens: 600
      fanout: user_turn
      max_tokens: 6000
      enabled: true

# 모델명과 provider는 내 Model Picker에 실제 표시되는 값으로 교체하세요.

MOA 총비용 공식

한 번의 사용자 요청에서도 레퍼런스 자문과 어그리게이터 호출이 각각 과금됩니다. 도구 호출 후 후속 모델 반복이 있으면 추가됩니다.

총비용 = Σ(레퍼런스 입력 + 출력) + Σ(어그리게이터 입력 + 출력) + 도구 반복 후 추가 호출
Solar 어그리게이터 예시: 입력 10,000토큰 + 출력 2,000토큰이면 약 $0.0054 (VAT 전). 여기에 레퍼런스 모델 비용이 별도로 더해집니다.
