ONE-MINUTE BRIEF

읽는 것보다 내가 먼저 답해야 남는다

요약을 읽으면 이해한 것처럼 느껴진다. 그런데 책을 덮고 내가 설명하지 못하면 아직 내 지식이 아니다.

AI에는 설명과 문제를 맡기고, 나는 먼저 답한 뒤 틀린 이유와 원문을 확인하는 방식으로 공부한다.

한 문장 결론

FINAL SUMMARY

글을 마무리하며

AI가 잘 설명했다는 사실과 내가 이해했다는 사실은 다르다. 자료 없이 다시 말할 수 있어야 내 지식이 된다.

학습 기록에는 공부한 시간보다 자료 없이 설명한 범위를 남긴다. AI의 요약과 인용은 원문 의미를 바꿀 수 있으므로 중요한 문장은 직접 대조한다. 회화는 완벽한 문장을 외우기보다 같은 상황을 표현을 바꿔 여러 번 말하고, 독서는 요약을 저장하기보다 내 질문과 반론을 한 줄씩 붙인다. 과제·시험·출판물은 기관의 AI 사용 규정을 확인해 보세요.

  1. 원문·학습 목표·허용된 AI 사용 규정을 확인해 보세요.
  2. 정답을 보기 전에 먼저 답하거나 말씀드립니다.
  3. 틀린 이유를 사실·문법·논리로 나누어 정리해보세요.
  4. 하루 뒤와 일주일 뒤 같은 문제를 다시 푼다.
