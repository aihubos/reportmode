ONE-MINUTE BRIEF

이름보다 지금 쓸 수 있는 범위를 먼저 확인한다

AI 소식은 기능 이름이 빠르게 바뀐다. 그래서 ChatGPT 커스텀 인스트럭션·메모리 활용도 발표 문구보다 지금 실제로 쓸 수 있는 범위부터 확인해 보았습니다.

현재 결과가 부족하다고 가능성을 닫을 필요는 없다. 다만 날짜, 가격, 지원 조건과 결과의 사실 여부는 마지막에 사람이 맞춰야 한다.

HOW TO USE IT

가격, context, output, 라이선스는 공식 문서의 기준일과 단위를 같이 저장해 두세요.

팁

지연, 사람 수정 시간, 검색·도구 호출과 self-host 운영비를 빠뜨리지 않는 것이 좋습니다.

작은 재현 테스트 시트

안 되는 건 없다고 생각하되, 평가 없이 넓히지는 않는 것이 좋습니다.
