공개 Site에는 비밀정보뿐 아니라 개인 일정, 내부 링크, 고객 정보, 미공개 성과도 넣지 않습니다.

넣어도 되는 후보

  • 별칭과 공개용 소개
  • 직접 만든 게임 화면
  • 자동화 구조 설명
  • 배운 점과 다음 목표
  • 공개 가능한 링크

넣지 않는 정보

  • 비밀번호·Token·API 키
  • 개인 Telegram ID·대화
  • 내부 문서와 고객 정보
  • 집 주소·개인 일정 원문
  • 권리 확인 없는 이미지

- 사이트 이름:

- 권리 확인이 안 된 이미지

배포된 버전

공개하기 전 배포 없이 검토용 버전을 저장합니다

Sites의 저장과 배포는 다른 단계입니다. 검토 후보를 먼저 저장하면 공개 전에 다시 확인할 수 있습니다.

01
화면 설명

Sites 프로젝트의 현재 미리보기와 변경 내용을 마지막으로 확인합니다.

02
실행할 행동

‘배포하지 말고 현재 상태를 검토용 버전으로 저장해줘’라고 요청합니다.

03
예상 결과

저장된 버전이 생기고 아직 공개 URL을 새로 배포하지 않은 상태가 표시됩니다.

04
완료 확인

버전의 제목·설명·저장 시각과 선택할 공개 범위를 기록합니다.

05
오류 시 대응

저장과 배포가 한 번에 진행될 것 같으면 중단하고 ‘save version only, do not deploy’ 의도를 다시 명확히 합니다.
