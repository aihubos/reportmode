## 업로드

1. ZIP의 `reports/` 폴더를 저장소 루트의 `reports/`에 병합합니다.
2. `archive-entry.json`과 `sitemap-entry.xml`을 기존 archive/sitemap 자동화 입력으로 사용합니다. 기존 파일 전체를 빈 내용으로 덮어쓰지 않습니다.
3. `upload-manifest.json`의 SHA256과 크기를 확인합니다. manifest 자체는 자기참조 해시 문제로 목록에서 제외되어 있습니다.
