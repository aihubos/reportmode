분석

Pro·Business·Enterprise의 한도를 읽는 법

Pro $100과 $200은 기능 차이보다 포함 사용량 차이가 핵심입니다. OpenAI는 각각 Plus 대비 5배와 20배로 설명하지만, 실제 한도는 모델·시간 창·시스템 상황에 따라 달라집니다. Business·Enterprise는 표준 좌석 기본 한도에 더해 크레딧으로 확장하는 구조이므로, 팀 예산은 ‘좌석비 + 월별 추가 크레딧 상한’으로 나누어 관리하는 편이 안전합니다.

  • Pro에서 ‘무제한’으로 표시되는 기능도 악용 방지 정책과 개별 모델 한도의 적용을 받습니다.
  • Enterprise·Edu의 유연 과금 환경은 고정 레이트 리밋 대신 크레딧에 따라 사용량이 확장됩니다.
  • Codex·ChatGPT Work·ChatGPT for Excel·Workspace Agents는 이용 가능한 경우 같은 에이전트 사용량·크레딧 풀을 공유합니다.

OpenAI API 현재 단가 — GPT-5.6 Sol·Terra·Luna

아래 API 단가는 표준·짧은 컨텍스트의 1M 토큰 기준입니다. ‘입력 1M + 출력 1M’ 열은 비교를 쉽게 하기 위한 단순 합계이며, 실제 청구액은 입력·캐시 입력·출력의 실제 비중과 도구 호출에 따라 달라집니다.

개인의 생산성 도구와 제품용 API는 구매 기준이 다릅니다. 개인은 실제 사용 빈도와 Codex 한도 압박을 보고 플랜을 선택하고, 팀은 사용자 수와 권한·데이터 관리·추가 크레딧 상한을 함께 정해야 합니다. 서비스 API는 모델별 단가가 아니라 월간 토큰량·캐시율·고난도 비율·도구 호출을 합친 비용 시나리오로 승인해야 합니다.

  • 개인 기본값: Plus에서 시작하고 실제 한도 부족이 반복될 때만 Pro 또는 크레딧을 검토합니다.
  • 팀 기본값: Business 좌석비와 별도 크레딧 예산을 분리하고, 새 Business의 Codex 전용 좌석 제한을 확인합니다.
  • 제품 API: Luna·Terra를 기본 후보로 두고 Sol·Opus·Pro급 모델은 복잡도 조건 또는 사람 승인 단계에만 올립니다.
  • 예산 통제: 월 한도, 모델별 라우팅, 캐시율, 장기 컨텍스트 발생률, 도구 호출을 운영 지표로 둡니다.

장점

  • Plus부터 Codex·고급 추론·앱 연동을 한 계정에서 쓸 수 있어 개인 도입이 단순함
  • Terra·Luna의 현재 API 단가가 낮아져 대량 업무의 비용 설계 폭이 넓어짐
  • Business·Enterprise는 좌석·권한·지출을 조직 단위로 관리할 수 있음
  • 여러 공급사의 저비용·고성능 모델을 업무 단계별로 나눠 비용을 최적화할 수 있음

단점

  • 구독 한도는 고정 메시지 보장이 아니라 작업 조건에 따라 변동함
  • API 비용은 어떤 ChatGPT 구독에도 포함되지 않아 별도 예산이 필요함
  • Pro의 5배·20배 정책은 모델별 절대 작업 수를 의미하지 않음
  • 경쟁사 가격만으로 품질·속도·한국어 성능·보안 적합성을 결론낼 수 없음
  • 가격·모델·한도는 자주 변경되므로 실제 결제와 도입 전 공식 페이지 재확인이 필요함
Decision Criteria

판단 기준

01

개인 업무의 시작점

주 몇 회 집중 코딩·기획이면 Plus($20)로 시작하고, 한도 부족이 반복되는 실제 사용 기록이 있을 때 Pro 또는 크레딧으로 확장합니다.

02

팀 도입 예산

Business는 표준 좌석비와 별도 크레딧 상한을 나누어 승인합니다. 새 워크스페이스의 Codex 전용 좌석 제한도 먼저 확인합니다.

03

API 기본 라우팅

대량·반복 작업은 Luna·Terra 같은 저비용 티어부터 검증하고, 복잡한 고가 작업만 Sol·Opus·Pro급으로 승격하는 조건을 둡니다.

04

월간 비용 보고

입력·출력·캐시·장기 컨텍스트·도구 호출을 별도로 집계하고, 구독료와 API 사용료를 한 숫자로 합치지 않습니다.
