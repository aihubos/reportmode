게시 전에 확인하고,
게시 뒤에도 다시 확인합니다.

이 임시 보고서는 Blog Hub v2가 자체 포함 HTML을 검사하고 GitHub Pages에 게시한 뒤 공개 주소와 아카이브를 확인하는지 검증하기 위해 만들어졌습니다.

01 · Preflight

시작 HTML과 모든 필수 상대 자산을 게시 전에 검사합니다.

02 · Publish

검수를 통과한 준비 파일만 Report Mode 게시기로 보냅니다.

03 · Verify

Pages SHA, 보고서, 아카이브, 최신 링크와 내부 자산을 확인합니다.

검증용 임시 보고서

실게시 증거를 수집한 뒤 Report Mode가 지원하는 삭제 기능으로 정리합니다.
