promptHermes에게 보내는 안전한 등록 요청
Asia/Seoul 기준 평일 오전 8시에 실행되는 ‘아침 3분 브리핑’을 만들어줘.

매 실행은 새 세션에서 시작하고, 내가 정한 지역의 날씨와 지난 24시간의 AI 뉴스 3개를 공식·원문 출처 우선으로 확인해줘. 각 항목은 제목, 2문장 요약, 원문 링크를 넣고 확인되지 않은 내용은 ‘미확인’으로 표시해줘. 전체는 모바일에서 3분 안에 읽을 길이로 작성해 현재 Telegram 대화로 보내줘.

등록하기 전에 작업 이름, 일정, 시간대, 전달 위치, 전체 프롬프트를 먼저 보여줘. 내가 ‘등록 승인’이라고 답한 뒤에만 실제 등록해줘.

CRON COMMANDSP.09 / 19

명령으로 목록·즉시 실행·중단을 통제합니다

<job_id>는 실제 목록에 나온 값으로 바꿉니다. 예시 ID를 그대로 입력하지 않습니다.

textTelegram/채팅 명령
/cron add "0 8 * * 1-5" "오늘의 날씨와 AI 뉴스 3개를 출처 링크와 함께 짧게 정리해줘."
/cron list
/cron run <job_id>
/cron pause <job_id>
/cron resume <job_id>
/cron remove <job_id>
shell터미널 대체 명령
hermes cron create "0 8 * * 1-5" "오늘의 날씨와 AI 뉴스 3개를 출처 링크와 함께 짧게 정리해줘." --name "아침 3분 브리핑" --deliver telegram
hermes cron list
hermes cron run <job_id>
hermes cron status
삭제 전list → pause → 확인 → remove 순서를 권장합니다. 이름이 겹치면 정확한 job ID를 사용합니다.
