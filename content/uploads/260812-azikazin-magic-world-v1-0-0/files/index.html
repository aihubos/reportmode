EXECUTIVE SUMMARY · ONE PAGE

Rolling Stone Japan과 CJ문화재단은 현재 팀을 5인 미디어믹스 창작 집단으로 소개합니다. 음악만 만드는 것이 아니라, 자체 캐릭터와 가상 마을을 중심으로 게임·애니메이션·공연·팝업·상품까지 하나의 세계로 연결합니다.12

사실: 공식·1차 출처에서 확인 해석: 공개 사실을 바탕으로 한 보고서 판단 미확인: 공개 발표를 찾지 못함

핵심 결론

Azikazin Magic World의 본질은 ‘앨범을 내는 밴드’보다 ‘음악을 엔진으로 캐릭터 세계를 운영하는 소규모 IP 제작사’에 가깝습니다. 작품이 곡·MV·게임 데모·공연·팝업·상품으로 순환하기 때문에, 팬은 청취자이면서 동시에 세계관의 플레이어가 됩니다.

01

현재 구조

2026년 공개 기준 5인입니다. 음악, 캐릭터·아트, 영상·게임, 3D CG, 공간·머천다이즈를 내부 역할로 나눕니다.

02

차별화 요소

실제 플레이 가능한 게임 또는 데모를 만들고, 그 화면을 애니메이션·뮤직비디오·라이브 콘텐츠로 재사용하는 ‘겜니메이션’ 방식입니다.

03

성장 신호

2025년 PlayStation×YOASOBI·IU 협업, 2026년 바르셀로나 쇼케이스·도쿄 팝업에 이어 8월 타이베이 음악제 출연이 예정돼 있습니다.

04

주의할 점

매출·조직 규모·멤버 변동 사유는 공개 범위가 제한적입니다. ‘성공한 대형 그룹’보다 성장 중인 독립 크리에이티브 IP 팀으로 보는 편이 정확합니다.

CURRENT MEMBERS · 2026

현재는 다섯 명이 서로 다른 제작 공정을 맡되, 최종 결과는 전원이 함께 결정합니다

CREATIVE OPERATING SYSTEM

작품 하나가 여섯 단계로 돌며, 다음 작품의 자산이 됩니다

‘겜니메이션(Game-nimation)’이란? 게임의 미학과 실제 플레이 화면을 애니메이션·뮤직비디오에 결합하는 팀의 표현입니다. 초기에는 기술 지원을 받았지만, 이후 Song Kiho가 게임 개발까지 맡았다고 설명합니다. 단, 모든 프로젝트가 완성형 상용 게임인 것은 아니며 영상용 데모 또는 전시형 게임도 포함됩니다.
