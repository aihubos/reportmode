# 새 보고서 요청

보고서모드로 아래 주제를 조사해 최종 HTML 파일을 만들어 주세요.

- 주제: [주제]
- 핵심 질문: [알고 싶은 것]
- 독자: [예: 비전공자 / 경영진 / 구매 검토자]
- 범위·지역: [예: 한국 우선, 글로벌 보완]
- 기준일: [오늘 / 특정 날짜]
- 깊이: [빠른 / 표준 심층 / 최대 심층]
- 반드시 포함: [비교, 가격, 기술, 시장, TAM·SAM, 리스크 등]
- 제외: [불필요한 범위]
- 참고 파일·URL: [있으면 기재]

요구사항:
1. 공식·공공·학술 원문을 우선하고 핵심 숫자를 재검증하세요.
2. 사실·분석·전망·루머를 구분하세요.
3. 반대 근거와 한계를 포함하세요.
4. templates/report-shell.html과 scripts/render_report.py를 사용하세요.
5. 정적 QA 후 실제 `YYMMDD-english-slug.html`을 `/mnt/data`에 생성해 다운로드 링크로 전달하세요.
6. 최종 결과물은 Markdown 설명이 아니라 HTML 파일입니다.
