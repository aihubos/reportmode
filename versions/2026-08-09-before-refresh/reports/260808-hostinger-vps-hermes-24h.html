EXECUTIVE SUMMARY

SECURITY & MAINTENANCE

VPS를 샀다고 자동으로 안전해지는 것은 아닙니다

가장 중요한 통제는 비밀번호가 아니라 접근 범위 최소화입니다. Hermes를 일반 사용자 또는 Docker로 격리하고, Telegram allowlist를 적용하며, 대시보드 포트는 공개하지 않고, 업데이트 전 스냅샷을 만드는 운영 습관이 필요합니다.[10][11]

SSH 키 + 일반 사용자

root 비밀번호 로그인을 일상적으로 쓰지 말고, SSH 공개키와 sudo 권한이 있는 전용 사용자를 사용합니다.

포트 최소화

Telegram gateway는 보통 outbound 연결만 사용합니다. 대시보드 9119와 API 8642를 인터넷에 그대로 열지 않습니다.

비밀키 분리

API 키·봇 토큰은 ~/.hermes/.env에 보관하고 Git·공개 문서·스크린샷에 넣지 않습니다. 파일 권한은 600을 권장합니다.

승인 모드 유지

위험한 명령은 사람이 승인하도록 approvals.mode를 manual 또는 smart로 두고, 처음부터 off로 바꾸지 않습니다.
