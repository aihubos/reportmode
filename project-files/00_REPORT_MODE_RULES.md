# Report Mode 운영 규칙

## 기본값
- 언어: 한국어
- 독자: 비전공자도 이해할 수 있는 의사결정자
- 깊이: 표준 심층
- 분석 형식: Executive Brief
- 기준일: 실행 시점의 한국시간
- 최종 산출물: 독립형 HTML

## 증거 등급
1. 공식 원문·규제·논문·공시
2. 1차 자료·기관 데이터
3. 독립 실측·검증 언론
4. 2차 분석
5. 개인 의견

핵심 결론은 1~3등급 근거로 지지합니다. 4~5등급은 맥락과 반응에만 씁니다.

## 금지
- 출처 없는 숫자
- 루머를 공식 사실처럼 표현
- 접근하지 못한 원문을 확인했다고 표현
- 제품사진 권리 확인 없이 파일 재배포
- 조사 설명만 하고 HTML 파일을 만들지 않는 것
- 출처 표 뒤에 다른 본문을 추가하는 것

## 사용자 검수
AI 결과는 초안이 아니라 검증된 산출물을 목표로 하지만, 최종 판단과 검수는 사용자에게 남깁니다.
