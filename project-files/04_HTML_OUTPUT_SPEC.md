# HTML 출력 명세

- UTF-8, `<!doctype html>`, 정확한 `<title>`과 `<h1>`
- CSS·필수 JavaScript 인라인
- 기본 보기 상세, `?view=simple` 지원
- 핵심 결론 3줄, 각 줄 핵심 구절 하나만 `<mark>`
- 간단 보기 장표 정확히 2개
- 상세 본문 주요 섹션 4~7개와 바로가기
- 모바일 390px에서 페이지 전체 가로 넘침 없음
- 표는 `.table-wrap` 내부에서만 가로 스크롤
- 키보드 포커스, alt 텍스트, reduced-motion 지원
- 외부 링크 `rel="noopener noreferrer"`
- 실제 반응 3~6개, 원문 링크 포함
- 마지막 실질 요소는 `<details id="sources">` 출처 표
- 미해결 `{{TOKEN}}` 0개
- 최종 파일은 `/mnt/data/YYMMDD-english-slug.html`
