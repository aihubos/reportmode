# Report Hub 날씨·시계 정렬 디자인

## 목적

메인과 모든 보고서의 `Report Hub / by Jeremy`를 화면 왼쪽에 정렬한다. 서울 날짜와 초 단위 시계는 한 줄로 키워 표시한다. 메인 도서관의 오른쪽 리포트 희망 댓글창 아래에는 Jeremy OS의 동탄8동 날씨 정보를 Report Hub 카드 언어로 축소해 배치한다. 메인 카드 공유와 보고서 PDF·공유는 글자 없는 동일한 선형 아이콘으로 통일한다.

## 승인된 구성

- 메인 브랜드 묶음은 화면 왼쪽 16px, 모바일 8px에 정렬한다.
- 워드마크와 제작자 서명도 브랜드 버튼 안에서 왼쪽 정렬한다.
- 시계는 `8월 9일 일요일 18:20:35` 순서의 한 줄이다.
- 날짜는 데스크톱 13px, 시간은 22px이며 숫자는 `tabular-nums`로 고정한다.
- 모바일·세로 A4에서는 날짜 11px, 시간 18px로 줄여 가로 스크롤을 막는다.
- 메인 오른쪽에는 `archive-right-rail`을 만들고 댓글창 다음에 날씨 카드를 둔다.
- 1280px 이상에서는 우측 영역 전체가 화면을 따라다니며, 그보다 좁으면 본문 안의 정상 흐름으로 돌아온다.
- 날씨 카드는 380px 우측 영역 폭을 그대로 사용한다. 흰색 표면, 회색 경계, Toss Blue 한 가지 강조색만 사용한다.
- 위치는 Jeremy OS와 동일한 `경기도 화성시 동탄8동`으로 고정한다.
- 현재 기온·상태·오늘 최고/최저·강수 확률과 이후 4일 예보를 보여준다.

## 데이터와 상태

- 정적 GitHub Pages에서 Open-Meteo를 브라우저가 직접 호출한다.
- 좌표는 위도 `37.1622202`, 경도 `127.1055509`, 시간대는 `Asia/Seoul`이다.
- 별도 API 키와 Jeremy OS 서버 연결은 사용하지 않는다.
- 성공 응답은 브라우저에 10분간 저장해 반복 호출을 줄인다.
- 로딩 중에는 카드 골격을 유지하고, 실패하면 설명과 `다시 시도` 버튼을 표시한다.
- 날씨 요청 실패가 댓글·검색·목록 기능을 막지 않도록 별도 스크립트에서 독립 실행한다.

## PDF·공유 아이콘

- 메인 카드 공유 버튼은 대표 이미지 왼쪽의 텍스트 영역 우측 상단에 둔다.
- 텍스트 영역에 아이콘 전용 여백을 확보해 어떤 대표 이미지와도 겹치지 않게 한다.
- 메인 공유 아이콘은 36px, 실제 보고서의 PDF·공유 아이콘은 동일한 40px 크기다.
- PDF는 문서와 아래 화살표, 공유는 사각형과 위 화살표의 Apple식 선형 형태를 사용한다.
- 화면의 `PDF 저장`, `공유` 글자는 제거하되 `aria-label`과 마우스 도움말은 유지한다.
- 공유 성공 시 1.8초 동안 체크 아이콘으로 바뀐 뒤 원래 공유 아이콘으로 돌아온다.
- 기존 링크 복사와 PDF 인쇄 동작은 변경하지 않는다.

## 범위

- 공통 브랜드 CSS/JavaScript와 버전을 갱신한다.
- 메인 생성기, 메인 CSS, 날씨 전용 JavaScript와 관련 테스트를 수정한다.
- 모든 실제 보고서는 공통 자산 버전만 갱신한다.
- 보고서 본문·제목·출처·댓글 데이터·조회수 데이터는 변경하지 않는다.
- 리다이렉트 전용 HTML에는 새 UI를 넣지 않는다.

## 검수 기준

- 메인과 실제 보고서에서 브랜드가 화면 왼쪽에 정렬된다.
- 서울 날짜와 시간이 한 줄이고 초가 실제로 변경된다.
- 390px, 768px, 1280px에서 상단 메뉴와 우측 카드가 겹치거나 가로로 튀어나오지 않는다.
- 날씨 성공 시 동탄8동 현재 날씨와 4일 예보가 표시된다.
- 날씨 실패 시 다시 시도할 수 있고 댓글 입력·목록·검색은 계속 작동한다.
- 메인 공유 아이콘이 대표 이미지와 겹치지 않고, 보고서 PDF·공유 아이콘의 크기와 선 굵기가 동일하다.
- 공개 Pages에서 상단 시계, 날씨, 기존 댓글창을 실제로 확인한다.
