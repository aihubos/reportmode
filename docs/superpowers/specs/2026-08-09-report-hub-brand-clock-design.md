# Report Hub 브랜드 시계 디자인

## 목적

공통 `Report Hub` 워드마크를 약 50% 키우고 `by Jeremy` 서명을 추가한다. 메인 도서관과 모든 실제 보고서의 상단 메뉴에 서울 기준 날짜, 요일, 초 단위 시간을 Apple식 절제된 타이포로 표시한다.

## 승인된 화면 구성

- 데스크톱 워드마크는 24px에서 36px로, 모바일은 20px에서 30px로 키운다.
- `by Jeremy`는 워드마크 바로 아래 11px 회색 보조 텍스트로 둔다.
- 시계는 `8월 9일 일요일`과 `17:25:08` 두 줄로 표시한다.
- 날짜는 작은 회색, 시간은 더 진한 16px 고정폭 숫자로 표시한다.
- 보고서의 넓은 화면에서는 브랜드, 시계, 가로·세로 전환 순으로 한 줄에 둔다.
- 세로 A4와 모바일에서는 브랜드·시계를 첫 줄, 보기 전환을 다음 줄에 둔다.
- 메인 도서관에서는 브랜드와 시계를 왼쪽 묶음으로 유지하고 방문자 수·블로그 카드는 오른쪽에 둔다. 모바일에서는 두 묶음을 두 줄로 배치한다.

## 동작

- 표시 시간대는 `Asia/Seoul`로 고정한다.
- 초 단위로 갱신하되 숫자 폭은 `tabular-nums`로 고정한다.
- `<time>` 요소에 ISO 날짜를 기록하고, 초마다 화면 읽기 프로그램이 반복 안내하지 않도록 실시간 알림 영역으로 만들지 않는다.
- 인쇄 시 기존처럼 플로팅 메뉴 전체를 숨긴다.

## 범위

- 공통 브랜드 CSS·JavaScript, 브랜드 버전, 생성기 템플릿과 테스트를 수정한다.
- 45개 실제 보고서는 공통 자산 버전만 갱신한다.
- 보고서 본문·제목·출처·댓글·방문자 데이터는 변경하지 않는다.
- 리다이렉트 전용 HTML 3개에는 UI를 삽입하지 않는다.

## 검수 기준

- 고정 시각 단위 테스트에서 한국어 날짜·요일과 24시간제 초가 정확하다.
- 메인과 보고서 모두 `Report Hub`, `by Jeremy`, 날짜, 요일, 초 단위 시간을 한 번씩 표시한다.
- 390px, 768px, 1280px에서 가로 스크롤과 겹침이 없다.
- 세로 A4에서 우측 메뉴가 화면 밖으로 나가지 않는다.
- 공개 Pages 배포 후 초가 실제로 변경되고 링크·전환 버튼이 유지된다.
