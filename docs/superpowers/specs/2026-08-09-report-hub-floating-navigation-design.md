# Report Hub 플로팅 내비게이션 디자인

## 목표

모든 실제 보고서에서 같은 플로팅 메뉴를 사용한다. `Report Hub`는 항상 왼쪽 상단에 보이며 메인페이지로 이동한다. 가로·세로 전환은 같은 메뉴 안에 배치하고, 보고서 제목은 문서 최상단 이동 링크로 동작한다. 기존 `버전 및 업데이트 히스토리`와 공통 `변경 이력`은 같은 위치의 `버전 및 업데이트 이력` 하나로 통합한다.

## 시각 방향

- Apple의 절제된 여백과 표면 처리, 기존 Eduflex 대시보드의 Toss Blue 체계를 결합한다.
- 기존 RH 사각 아이콘은 보고서와 도서관 헤더에서 제거한다. 파비콘은 작은 브라우저 아이콘 식별을 위해 RH를 유지한다.
- 워드마크는 `Report Hub` 글자만 사용한다.
- 기본 색상은 Toss Blue `#3182F6`, 호버는 `#1B64DA`, 선택 배경은 `#E8F3FF`를 사용한다.
- 글꼴은 Pretendard, Apple 시스템 폰트 순서다. 워드마크는 데스크톱 24px, 모바일 20px, 굵기 850 이상으로 사용한다.
- 플로팅 표면은 흰색, 옅은 경계선, 한 단계의 부드러운 그림자만 사용한다.

## 플로팅 메뉴

- 위치: 화면 왼쪽 상단 16px, 모바일 10px.
- 구성: 큰 `Report Hub` 워드마크와 가로·세로 세그먼트 버튼.
- 데스크톱에서는 한 줄, 모바일에서는 한 줄을 유지하되 간격과 버튼 폭을 줄인다.
- 항상 fixed로 유지하며 보고서별 기존 스타일보다 높은 z-index를 사용한다.
- 인쇄 시 플로팅 메뉴 전체를 숨긴다.

## 동작

- `Report Hub` 클릭: `https://aireport.ai-hub-os.com/`으로 이동한다.
- 보고서의 모든 대표 `h1` 제목: 클릭 또는 Enter/Space 입력 시 최상단으로 이동한다.
- 가로·세로: 모든 실제 보고서에 공통 레이아웃 CSS와 JS를 정확히 한 번 주입한다.
- 기본 모드는 가로다. 세로 선택 시 기존 A4 축소 폰트와 인쇄 방향을 유지한다.
- 기존 간단·상세, PDF, 공유, 조회수, 댓글, 우측/하단 메뉴는 변경하지 않는다.
- 기존 이력 영역은 공통 이력 카드 하나로 교체하고, 내용 검토 결과·현재판·이전판 링크를 한 표에서 제공한다.
- 이전판이 없는 신규 보고서는 현재판만 표시한다.

## 적용 범위

- 현재 실제 보고서 45개.
- 이후 빌드 또는 업로드되는 실제 보고서.
- 공통 레이아웃 스크립트를 불러오는 이전판 보고서.
- 호환용 리다이렉트 3개는 이동 전용 상태를 유지한다.

## 검증 기준

- 실제 보고서 45개 모두 홈 링크, 브랜드 스타일/스크립트, 레이아웃 스타일/스크립트를 각각 하나만 가진다.
- 390px, 768px, 1280px에서 가로 스크롤과 제목 겹침이 없다.
- 현재 보고서, 최신 원본형 보고서, Hermes, 이전판에서 같은 플로팅 메뉴가 보인다.
- 제목 클릭 후 `scrollY`가 0에 가까워진다.
- 도서관 헤더는 텍스트 워드마크 하나만 보이고 중복 플로팅 메뉴가 생기지 않는다.
- 각 보고서의 `.report-history`와 `.report-history-shared-card`는 각각 하나이며 구형 확장 카드가 남지 않는다.
