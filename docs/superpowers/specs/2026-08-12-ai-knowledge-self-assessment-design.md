# AI 지식 자가진단 슬라이드 보고서 디자인

## 목표

`[자가진단] 나의 AI 관련 지식은 어느 수준?`을 Report Hub 도서관에 공개한다. 사용자가 제공한 10개 이미지를 한 화면에 한 장씩 보여 주고, 초급부터 연구·최전선까지 자신의 AI 지식 수준을 가볍게 점검할 수 있게 한다.

## 범위

- 보고서 ID: `260812-ai-knowledge-self-assessment`
- 보고서 경로: `reports/260812-ai-knowledge-self-assessment/`
- 이미지: 워드클라우드 5장과 용어표 5장을 보고서 내부 `assets/`로 복사한다.
- 도서관 카드: 첫 번째 초급 워드클라우드를 대표 이미지로 사용한다.
- 기존 보고서, 도서관의 다른 카드, 공유 공통 기능은 변경하지 않는다.

## 화면 경험

- 첫 진입부터 첫 번째 이미지가 전체 화면을 채운다. 별도 표지 슬라이드는 만들지 않는다.
- 화면 상단에는 작은 제목과 현재 단계만, 하단에는 `현재 / 전체` 진행 표시만 둔다.
- 이미지 비율은 보존한다. 배경을 사용해 남는 공간을 채우고 이미지를 자르지 않는다.
- 다음·이전 버튼, 키보드 좌우 화살표, 모바일 좌우 스와이프로 한 장씩 이동한다.
- 자동 재생은 사용하지 않는다. 표와 용어를 읽다가 원치 않게 넘어가는 문제를 막는다.
- `prefers-reduced-motion`에서는 전환 효과를 최소화한다.

## 이미지 순서

1. 초급 워드클라우드
2. 초급 용어표
3. 중급 워드클라우드
4. 중급 용어표
5. 심화 워드클라우드
6. 심화 용어표
7. 전문가 워드클라우드
8. 전문가 용어표
9. 연구·최전선 워드클라우드
10. 연구·최전선 용어표

## 접근성 및 반응형

- 버튼에는 한국어 접근성 이름을 넣고, 현재 슬라이드 번호를 `aria-live`로 알린다.
- 키보드 초점이 보이도록 한다.
- 390px 모바일과 데스크톱에서 가로 스크롤·이미지 잘림 없이 작동해야 한다.
- Report Hub 브랜드 링크와 기본 보고서 공통 스크립트는 유지한다.

## 검수와 공개

- 10개 자산 존재 여부, 카드의 대표 이미지 경로, 보고서의 10개 슬라이드 순서를 확인한다.
- 데스크톱과 390px에서 첫·마지막 슬라이드, 버튼·키보드 이동, 가로 넘침, 콘솔 오류를 확인한다.
- `npm run reports:integrity`, `npm run reports:brand-qa`, `npm run reports:view-id-qa`, `npm test`, `npm run typecheck`을 실행한다.
- GitHub Pages 빌드가 대상 커밋으로 완료된 뒤, 공개 보고서와 도서관 카드에서 다시 확인한다.
