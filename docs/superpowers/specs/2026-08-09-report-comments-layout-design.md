# Report Hub 세로 레이아웃·댓글·도서관 디자인

## 목표

모든 현재 보고서에서 세로 A4 보기의 플로팅 메뉴를 오른쪽 여백으로 옮기고, 표·코드·미디어가 본문 밖으로 튀어나오지 않게 한다. 모든 실제 보고서에는 방문자 간 공유되는 댓글을 제공한다. 메인 도서관은 소개성 카드를 덜어내고 보고서 탐색과 네이버 블로그 이동에 집중한다.

## 화면 규칙

- 기본 보고서 보기는 가로·상세를 유지한다.
- 1180px 이상에서 세로 A4를 선택하면 `Report Hub`와 가로·세로 전환 메뉴를 A4 용지 오른쪽 여백에 세로로 배치한다.
- 오른쪽 여백이 부족한 화면에서는 우측 상단의 한 줄 메뉴로 전환하고, 700px 이하에서는 화면 안쪽 8px 여백을 지킨다.
- 세로 A4 제목은 h1 최대 36px, h2 최대 28px, h3 최대 22px로 제한한다.
- 넓은 표·코드·iframe·canvas·video는 내용을 자르지 않고 해당 요소 안에서만 가로 이동한다. 이미지와 미디어는 본문 폭을 넘지 않는다.
- 인쇄 시 플로팅 메뉴와 댓글은 숨기고 현재 선택한 가로·세로 방향을 유지한다.

## 댓글 규칙

- 현재 실제 보고서에 공통 댓글 CSS와 JS를 한 번만 삽입한다. 리다이렉트 페이지와 과거 스냅샷은 제외한다.
- 댓글은 본문 다음, `버전 및 업데이트 이력` 앞에 놓는다.
- 이름·비밀번호·내용은 필수다. 비밀번호는 4글자 이상이며 브라우저에 저장하지 않는다.
- 작성자는 작성 비밀번호로 자기 댓글을 수정·삭제할 수 있다.
- 관리자 비밀번호는 모든 댓글을 수정·삭제할 수 있다.
- `Jeremy`와 `제레미`는 서버가 관리자 비밀번호를 확인한 경우에만 허용하며, 서버가 반환한 관리자 표시만 화면에 보여준다.
- 등록·수정·삭제는 로딩·성공·오류 상태를 같은 영역에서 안내하고 브라우저 prompt/alert는 사용하지 않는다.

## 메인 도서관 규칙

- 기존 Report Hub 소개·전체 보고서·최근 작성·자동 업데이트 카드를 제거한다.
- `읽고 판단하기 좋은 리서치만 모았습니다` 소개 카드를 제거한다.
- 네이버 블로그 링크는 상단 고정 메뉴 안의 초록색 카드 하나만 유지한다. 일반 텍스트 링크와 푸터 중복 링크를 제거한다.
- 보고서는 기본 30개를 표시한다. 사용자는 5개·10개·20개·30개 중 선택할 수 있다.
- 표시 개수 선택은 검색·분류·페이지 이동과 함께 동작하며 URL에 `size`로 반영한다.

## 검증 기준

- 모든 실제 보고서가 댓글 CSS/JS와 레이아웃 CSS/JS를 각각 정확히 한 번 가진다.
- 댓글 등록 후 새로고침, 사용자 수정, 사용자 삭제, 관리자 수정·삭제가 실제 저장소에서 유지된다.
- 잘못된 비밀번호와 관리자 사칭 이름이 서버에서 거부된다.
- 390px, 768px, 1280px에서 문서 전체 가로 스크롤이 없고 본문·댓글·메뉴가 겹치지 않는다.
- 메인 도서관의 네이버 링크는 하나이며, 초기 목록은 30개다.
