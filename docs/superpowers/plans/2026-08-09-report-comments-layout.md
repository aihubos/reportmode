# Report Hub 세로 레이아웃·댓글·도서관 구현 계획

**목표:** 승인된 공통 레이아웃, 공유 댓글, 단순화된 메인 도서관을 현재 보고서와 향후 생성 경로에 함께 적용한다.

**구조:** `report-page-layout`이 A4 배치와 넘침 처리를 맡고, 새 `report-comments` 자산이 댓글 UI를 맡는다. Cloudflare Worker와 D1이 작성자·관리자 권한과 영속 저장을 처리한다. `public-brand`와 보고서 렌더러가 공통 자산을 중복 없이 삽입한다. 메인 도서관은 렌더러와 현재 정적 결과를 함께 수정한다.

## 작업 순서

- [ ] 레이아웃, 댓글 권한, 공통 자산 주입, 도서관 목록 동작 테스트를 먼저 추가하고 실패를 확인한다.
- [ ] DESIGN.md에 A4 메뉴, 댓글, 네이버 카드 토큰을 추가한다.
- [ ] 세로 A4 우측 여백 메뉴, 작은 제목, 내부 가로 스크롤 래퍼를 구현한다.
- [ ] 댓글 작성·조회·수정·삭제 UI와 오류·빈 상태를 구현한다.
- [ ] Worker에 필수 이름, 관리자 이름 보호, 댓글 수정, 관리자 수정·삭제를 구현하고 D1 마이그레이션을 추가한다.
- [ ] 공통 자산을 현재 실제 보고서와 향후 생성 경로에 삽입한다.
- [ ] 메인 소개 카드 두 개와 중복 블로그 링크를 제거하고 초록색 블로그 카드 하나와 5·10·20·30 선택기를 구현한다.
- [ ] 단위·통합 검사 후 댓글 등록→새로고침→수정→새로고침→삭제와 관리자 권한을 검증한다.
- [ ] 390px, 768px, 1280px와 인쇄 화면을 실제 브라우저에서 확인한다.
- [ ] Worker 마이그레이션과 코드를 배포한 뒤 GitHub Pages를 공개하고 라이브 동작을 재검증한다.
